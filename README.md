# 🎧 MOOZIC

### Your Music. Your Rules.

MOOZIC is a modern Android music player designed for a smooth,
minimal and ad-free listening experience.

## ✨ Features

- Clean, modern dark interface
- Local music library
- Online audio streaming through direct URLs
- Background music playback
- Media session integration
- No advertisements
- Lightweight design

## 🛠️ Technology

- Kotlin
- Jetpack Compose
- AndroidX Media3
- ExoPlayer
- MediaStore

## 📱 Minimum Requirements

- Android 6.0+
- Internet connection for online streaming
- Storage audio permission for local music

## 🚀 Project Status

Version: 0.1.0

Status: Initial development
